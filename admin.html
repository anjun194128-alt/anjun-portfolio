GitHub Authorization

登录作品集后台

仅拥有作品集仓库编辑权限的账号可以发布。

首次登录：创建仓库授权密钥
  1. 前往 GitHub 创建细粒度授权密钥，使用你的 GitHub 账号登录。
  2. Repository access 选择 Only select repositories，只勾选 anjun-portfolio。
  3. Repository permissions 中的 Contents 设为 Read and write，设置有效期并生成密钥。
  4. 将密钥填入上方登录框。密钥仅在本次会话中使用，退出或刷新后需要重新登录。
